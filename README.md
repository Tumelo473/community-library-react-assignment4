# Community Library Management System

BIWA2110 Web Application Development - Individual Assignment 2

## Features
- React functional components and hooks
- React Router navigation
- Login form
- Dashboard
- Book management: add, update, delete
- Stock/availability management
- Transaction history
- User management: add, update, delete
- Low-stock highlighting for fewer than 2 copies
- Local Storage persistence
- Responsive CSS interface

## Run the project

1. Install Node.js.
2. Open this folder in VS Code.
3. Open the VS Code terminal.
4. Run:
   npm install
5. Then run:
   npm run dev
6. Open the localhost address shown by Vite.
